# ADR 0007: Deterministic finding key and overlap matrix

## Status

Accepted (2026-10-07).

## Context

The headline result of assay is how little different models' findings
overlap. That number is meaningless unless two reports of the same issue
from two models collapse to the same identity, regardless of how each model
phrased the path, cased the method or ordered its arguments. The overlap
output is also committed under `results/`, so it must be byte-stable across
runs and machines.

## Decision

- `internal/finding.NormalizePath` lower-cases, strips scheme, host, query
  and fragment, replaces numeric segments with `{id}` and UUIDs with
  `{uuid}`, collapses repeated slashes, drops the trailing slash and keeps
  the leading one.
- `DedupKey(lab, class, method, pathTemplate, param)` is the hex SHA-256 of
  `encoding/json` output for a struct whose fields are declared in
  alphabetical JSON-name order: `class, lab, method, param, path_template`.
  Method is upper-cased and the path normalized inside the function, so
  callers cannot produce two keys for one location. The package depends
  only on the standard library and `internal/model`.
- A finding's `ID` is `"f-" + DedupKey[:16]`; models never choose ids.
  Findings start `theorized`; `Transition` permits only
  theorized -> validated | refuted | declined.
- `Merge` keeps the earliest `FirstSeen`, the latest `LastSeen`, the higher
  severity, and unions evidence, tool-call ids and audit references.
- `internal/overlap.Compute` sorts model names and keys, records membership
  as sorted model indexes, computes pairwise Jaccard, per-model unique
  keys, union and intersection, and carries input file digests. `PRF`
  scores findings against ground-truth entries keyed the same way.
  `Encode` uses `encoding/json` with indentation; struct field order and
  sorted map keys make the bytes stable, and nil containers are normalized
  to empty ones first. `assay overlap --check FILE` recomputes and exits 1
  on any byte difference.

## Consequences

- Two models reporting `/api/users/42?x=1` and `/API/users/7` with the same
  class, method and parameter collapse to one key; different parameters or
  methods stay distinct by design.
- Templating is lexical, not semantic: a numeric path segment that is not
  an identifier is still templated. This is accepted for stability.
- The overlap statistic can be regenerated by anyone from the committed
  finding files and verified byte-for-byte in CI.
